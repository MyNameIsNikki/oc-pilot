# Changelog

## 0.88.1

- CI: release workflow поддерживает `NPM_TOKEN` как запасной путь публикации; без секрета остаётся OIDC Trusted Publishing.
- Токен читается только из GitHub secret, не печатается в логах, а созданный `.npmrc` удаляется после публикации.
- Runtime не менялся; 661 тест; версия 0.88.1.

## 0.88.0

- Новая команда `hivemind`: P2P-сеть агентов на встроенном `node:net` — `init`, `trust`, `status`, `serve`, `send`.
- Каждое соединение проходит подписанный ed25519 handshake и ECDH X25519; сообщения шифруются AES-256-GCM, а недоверенные ключи отбрасываются до чтения данных.
- По сети разрешены только diff, AST и LLM-запросы; payload с command/exec/script отклоняется, поэтому удалённого исполнения кода нет.
- MCP-инструмент `hivemind_status` и промпт `join-the-swarm` проверяют identity и доверенных узлов; `serve` и `send` работают только с явным `trust`.
- Документация и skill; 661 тест; версия 0.88.0.

## 0.87.0

- Новая команда `sandbox run <file>`: запуск самодостаточного JS/ESM в `node:vm` с отдельным контекстом.
- Статические импорты, `require`, `fetch`, `process.exit` и таймеры длиннее секунды блокируются; console перехватывается, а таймаут и лимит кучи ограничивают исполнение.
- TypeScript запускается только из собранного `dist/*.js`; для нативного кода песочницы нет, `--allow-unsafe-exec` остаётся явным подтверждением.
- MCP-инструмент `sandbox` и промпт `sandbox-script` показывают статус ok/blocked/timeout/error и точный вывод.
- Документация и skill; 658 тестов; версия 0.87.0.

## 0.86.0

- Новая команда `query`: цепочный AQL вместо SQL — `find(CallExpression).where(name, 'stripe').select(file, line)`.
- Граф строится текстовым проходом по репозиторию: File, Function, Class, Import, CallExpression; шаги find, where, sort, limit, select, count.
- Запрос не требует парсера грамматики и работает офлайн; MCP-инструмент `query_ast` и промпт `query-the-ast` дают агенту file:line-доказательства до правки.
- `--limit` ограничивает выдачу, `--json` отдаёт строки и счётчик; это не полный TypeScript AST, а быстрый граф для навигации.
- Документация и skill; 655 тестов; версия 0.86.0.

## 0.85.0

- `fix --shadow` и `battle --shadow`: применённый патч выполняется в отдельном git worktree `.oc-pilot/shadow-tree`, а не в рабочем дереве.
- Тесты, линтеры и внешние компиляторы видят изменённые файлы, потому что shadow — настоящая файловая система, а не in-memory proxy.
- Diff извлекается из shadow через `git diff`, проверяется `git apply --check` и применяется к рабочему дереву только при успешном прогоне; при падении диск остаётся нетронутым.
- `--shadow` требует `--apply`; shadow worktree удаляется в `finally`, а путь исключён из git.
- Документация и skill; 652 теста; версия 0.85.0.

## 0.84.0

- Новая команда `bankruptcy`: детерминированный прогноз техдолга по последним коммитам — ослабленные тесты, SAST high/medium, TODO, churn и slop-прокси.
- Ряд сглаживается скользящим средним за 14 дней, выбросы выше mean+2σ исключаются, линейная регрессия даёт скорость и дату достижения порога 100.
- `--history 30d`, `--format text|json|svg` и `--explain`: формула, веса и правила сглаживания; тесты и безопасность весят больше TODO.
- Меньше 10 коммитов — `[INSUFFICIENT DATA: Need at least 10 commits to compute Slop Velocity]`; MCP-инструмент `bankruptcy` и промпт `forecast-tech-debt` работают офлайн.
- Документация и skill; 650 тестов; версия 0.84.0.

## 0.83.0

- Новая команда `fuzz`: безопасный JIT-фаззинг экспортируемых функций из diff мусорными входами — null, -1, пустая строка, 10 МБ, `__proto__`, пустые контейнеры.

- MCP-инструмент `fuzz` (офлайн, read-only) и промпт `fuzz-the-diff`; `--fail-on-crash` превращает падение в код 1.
- Документация и skill; 647 тестов; версия 0.83.0.
